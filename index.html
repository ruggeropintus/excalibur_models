Project Excalibur

Welcome to the digital repository that features digitized archaeological artifacts acquired during the Toolkit 1 activity of the project Excalibur. Toolkit 1 is developed by CRS4, and the objects showcased in this repository originate from Use Case 2 (Partner: SA) and Use Case 3 (Partner: SMAEK). Explore the artifacts through interactive relightable image visualization obtained from MLIC data, powered by OpenLIME.
